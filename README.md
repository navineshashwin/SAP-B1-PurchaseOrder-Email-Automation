## SAP Business One – Purchase Order Email Automation

This project is a SAP Business One C# UI Add-on that automates Purchase Order email delivery.

### Key Features
- Custom "Send E-Mail" button in Purchase Order screen
- Automatic PO PDF generation using Crystal Reports
- Reads documents from PO Attachment tab
- Merges PO PDF with attached documents
- Sends a single consolidated PDF to vendor via email

### Technologies Used
- SAP Business One UI API & DI API
- C#
- Crystal Reports
- iText7 (PDF merge)
- SMTP Email Integration
