## SAP Business One – Purchase Order Email Automation

This project is a SAP Business One C# UI Add-on that automates
Purchase Order email delivery to vendors.

---

## 🔹 Key Features
- Custom **Send E-Mail** button in Purchase Order screen
- Automatic PO PDF generation using Crystal Reports
- Reads files from the PO **Attachments** tab
- Merges PO PDF with attached documents into a single PDF
- Sends consolidated PDF to vendor via email (SMTP)

---

## 🛠 Technologies Used
- SAP Business One UI API
- SAP Business One DI API
- C#
- Crystal Reports
- iText7 (PDF merging)
- SMTP Email Integration

---

## 📌 Business Value
- Eliminates manual PO emailing
- Ensures all attachments are included
- Reduces errors and processing time
